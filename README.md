# Car Price Prediction 🚗

A Machine Learning project that predicts the price of a car based on different features like brand, model, year, mileage, and other specifications.

## 🚀 Project Overview

This project uses Machine Learning algorithms to estimate used car prices. The model is trained on a car dataset and deployed using FastAPI.

## 🛠️ Technologies Used

- Python
- Machine Learning
- Pandas
- NumPy
- Scikit-learn
- FastAPI
- Joblib
